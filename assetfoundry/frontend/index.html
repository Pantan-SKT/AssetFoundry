Bereit für dein eigenes 3D-Modell

AssetFoundry funktioniert unabhängig vom Generierungsmodell. Du hinterlegst lediglich einen kompatiblen ComfyUI-API-Workflow.

  • PNG-Input-Node
  • Verkettete 3D-Generierung
  • SaveGLB- oder kompatibler Export-Node
  • Genau eine GLB pro Auftrag
Der normale ComfyUI-Oberflächen-Export ist kein API-JSON. Exportiere ausdrücklich das API-Format.
